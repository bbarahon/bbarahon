### 🗂️ Featured Software & Data Science Projects

#### 🛰️ [Supplier Risk Radar](https://github.com/bbarahon/Supplier_Risk_Radar_Repository_Grupo10)
**Python · scikit-learn · TF-IDF · Logistic Regression · Flask · pandas**

A supplier-monitoring system that analyzes news articles to identify **supply-chain risks**, determine their **urgency**, and match events to affected suppliers. It combines text classification with domain-specific risk rules and supplier-dependency information. A web dashboard presents alerts, historical incidents, material coverage, and estimated financial impact to support procurement decisions.

#### 📚 [What Makes a Book Highly Rated?](https://github.com/bbarahon/What-makes-a-book-highly-rated-Practical-Applications-1-2)
**Machine Learning · Weka · Classification · Feature Selection · Model Interpretability**

A study of whether bibliographic metadata can distinguish highly rated books from lower-rated ones. The project explores multiple classifier families and feature-selection approaches, with an emphasis on **careful evaluation and understanding model behavior**, rather than treating predictive accuracy as the only goal.

#### 🌌 [STARS — Synthetic Templates for Astrochemical Radio Surveys](https://github.com/bbarahon/CAB-Internship-tool)
**Python · Jython · MADCUBA · NumPy · SciPy · Matplotlib**

Research software developed during my internship at **CAB (INTA–CSIC)**. A Jython tool integrated with **MADCUBA** generates synthetic molecular spectra, followed by a Python workflow for visualization and statistical analysis of molecular lines in an interstellar cloud. The repository includes example files, notebooks, and user guides.
